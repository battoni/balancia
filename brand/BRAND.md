## Symbol

Two complementary rounded forms, one over the other, split by a rising S-shaped gap. Read
together, they are a soft "B" and a balance that closes: two sides that fit along one curve.

| | |
| --- | --- |
| Canvas | 512 × 512, mark bounds x 82–438, y 52–460 (356 × 408) |
| Top form | Petrol teal `#0e5a5c`; flat top and vertical left edge, round right side, its lower edge falls gently to the left |
| Bottom form | Mint `#2fb7a3`; same left edge, a domed top edge parallel to the gap, the widest form |
| Gap | ~38 units, even along its whole length (stays open at real 16px) |
| Corners | Every small corner is the same 36-unit radius; every join is tangent-continuous (no kinks) |
| Paths | 2, solid fills, no strokes, no background |

## Wordmark

- **Manrope**, outlined at **wght 800**. That matches the browser render of `font-weight: 700` that the owner approved: Chrome draws Manrope 700 heavier than the font's own 700 master. See the comment in `build.py`.
- Tracking: -0.02 em.
- The text is "Balancia", capitalised. Never all caps, never all lowercase.

## Lockup

- Horizontal, icon on the left.
- Wordmark cap height = 0.80 × icon height. Both are vertically centred.
- Space between the icon and the wordmark = 0.40 × icon height.
- No stacked lockup in v1. Square uses take the icon alone.

## Clear space and minimum size

- **Clear space:** 0.25 × icon height on every side (the files carry 0.12; add the rest in layout).
- **Minimum lockup height:** 20px on screen, 8mm in print.
- **Minimum icon:** 16px. It was tested at real 16px.

## Scale

| Size | Use |
| --- | --- |
| 16–32px | Icon only: favicon, browser tab, "powered by" signature |
| 24–40px tall | Lockup: navbar and console header |
| 64px+ | Lockup: login, site hero, pitch deck |

## Never

- Recolour outside the four versions, or put a gradient on it.
- Add a stroke or a shadow, or squeeze or rotate it.
- Change the gap: never close it, never widen it.
- Put the light version on a dark background, or the reverse.
- Set the wordmark in live text instead of the outlined file.
- Place it on a busy photo without the white version and a scrim.
- Pair it with any Reforma, flag or government imagery.
